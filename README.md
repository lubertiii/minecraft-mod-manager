Reminders:

Naming Conventions Used:
classes: NewClass
functions: newFunction
variables: new_variable


Description:
This project provides assistance in updating mods in the mods folder to automate replacing of old versions with newer ones.

This tool is for those who does not want to use separate launchers with its own mod management feature and only want to use the Minecraft Launcher.
